# 🚀 Frontend Progress Wallpaper

A live wallpaper that shows your coding progress through the year. Automatically updates daily!

## Features
- ✅ **Automatic daily updates** (no manual intervention needed)
- ✅ **PWA support** - Install on home screen like a native app
- ✅ **Works offline** after first load
- ✅ **Beautiful gradient design** with smooth animations
- ✅ **Responsive** - Works on all mobile devices
- ✅ **Cross-platform** - iOS & Android compatible
